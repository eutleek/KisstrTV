# KisstrTV 🎬

> 无边框、全屏、电台式音乐 MV 播放器 —— 永远放不完的热门精选随机播放。
> 音悦 TV 的精神续作。

KisstrTV 把"看 MV"还原成最原始的体验：打开软件，热门精选 MV 就像电台一样一首接一首自动播放，没有歌单焦虑、没有选择困难，想切频道点一下频道卡即可。

---

## ✨ 特性

- **电台式随机播放**：无需建歌单，打开即播，永远放不完
- **23 个频道 / 6900 条精选曲库**：华语、粤语、欧美、日语、韩语、怀旧金曲、Live 现场、4K 修复等频道，每频道内置 300 条精选 MV（B站 4749 条 + 网易云 MV 2151 条，按播放量精选、过滤直播切片与教程水视频）
- **全屏无边框沉浸体验**：全局黑白极简 UI，控件悬停即现、移开即隐
- **三版任选**：安装版 / 文件夹版 / 独立文件版（见下方下载）
- **系统托盘驻留**：点 ✕ 最小化到托盘并自动暂停，右键托盘可真正退出
- **迷你悬浮窗**：主窗与迷你窗均严格锁定 16:9
- **丝滑等比缩放**：OS 原生 setAspectRatio 实时联动宽高，拖拽缩放零跳变
- **失效救济机制**：单条片源解析失败不拉黑；曲库枯竭时自动重置失效名单，恢复完整曲库
- **B站 / 网易云账号登录**：登录后可解锁账号相关能力（含登录页缓存修复，桌面 UA 渲染）

## 🖱 交互约定

| 操作 | 效果 |
|---|---|
| 单击视频 | 暂停 / 播放 |
| 双击视频 | 最大化 / 还原 |
| 点击频道卡片 | 切换频道并起播（点当前频道不换片） |
| 拖拽画面 / 顶栏空白 | 移动窗口 |
| 拖拽四角 | 等比缩放窗口（松手自动归正 16:9） |
| 点 ✕ | 最小化到托盘（自动暂停） |
| 托盘右键 → 退出 | 真正退出程序 |

## 🛠 从源码构建

```bash
# 环境要求：Node.js 18+
npm install        # 或直接使用仓库附带的 node_modules
npm run dist       # 输出 portable + nsis 安装包
```

技术栈：Electron ^31 + 原生 HTML/JS/CSS 单页 + electron-builder ^24。
（Windows 下首次打包建议预置 winCodeSign 缓存，详见仓库内编译说明。）
