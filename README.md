## 快速体验（不装任何东西）

直接双击 `index.html`，用浏览器（Chrome / Edge）打开即可使用大部分功能。

## 全站热门随机播放（重点）

像 FM 广播电台一样：每个频道有它自己的风格，播放永不枯竭，每天听到的歌都不一样，且都是优质/上榜内容。

**电台分层播放（v6）**：
1. **分类合集（主题池）**——点频道先播该主题的曲库池（内置种子 + 相关视频链挖掘 + 搜索补充），随机连播；
2. **分 P 合集拆单曲**——遇到"OP/ED 合集/分P 收藏向"这类多 P 视频（如《中华一番 OP&ED 合集》13P、《彻夜之歌 OP&ED》5P），**自动把每个分 P 拆成独立单曲**进队列随机播（一部合集 = 十几到几百首），长合集（如 1995/1998 年 TV 动画 OP-ED 大合集）则整段连播；
3. **官方推荐续播**——主题池播完后，自动接入"官方热门池"（B 站官方热门里的音乐/动漫精选，**每次启动刷新**，所以每天不一样），永不枯竭；
4. **持续自动挖掘**——播放中每约 42 秒自动用曲库新发现继续挖"相关视频"，越推越多。

**本地曲库（vault）**：所有抓到的音乐/动漫视频去重后存本机（`vault.json`），**跨会话累积、越用越多**，二次打开即有完整曲库；状态栏「曲库 N」实时显示。实测：动漫频道一次会话即可累积上千首主题曲库；全库已从几百涨到 2300+。

> 关于规模说实话：原版音悦台巅峰号称收录十几万条，但那含大量网友投稿/低质内容；B 站没有现成的「官方 MV 库」接口，匿名搜索会被风控（单关键词上限约 1000 条）、全站热门只有 600 多条——**匿名能稳定积累到几千~一万多条**；要达到"几万条"需要登录 B 站账号（登录后搜索翻页稳定、还可抓 UP 主全部分区投稿）。另外 B 站上动漫**官方 OP/ED** 本身约一千多首，本曲库做的是"动漫音乐相关视频"大池子（OP/ED、合集、翻唱、AMV、现场、翻跳等），这才是能到数万条的方向，且会优先官方与热门。

## 网易云片源

- 网易云 Web 接口对**匿名**访问一律风控（实测被拒），因此**必须登录后使用**。
- 点「登录网易云」→ 弹出登录窗口（手机号/扫码均可），登录成功后该会话即被本程序复用；
- **登录后自动扩充**：任意频道播放时，会自动用该分类的关键词同步搜网易云 MV 并混进队列；
- 也可在「搜网易云 MV」输入歌手/歌名（如「晴天」「起风了」）→ 点「＋加入」手动加进当前频道，或直接粘贴网易云 MV 链接：`https://music.163.com/#/mv?id=504177`。
- 登录信息只存本机（Electron `persist:netease` 会话），不会上传。

## 关于 QQ 音乐源（实测结论，诚实说明）

QQ 音乐的 MV 播放直链**必须携带登录签名 + vkey（动态加密票据）**才能取得，票据有效期很短且接口经常变动。实测：老接口 `mv_getinfo` 已失效返回空；搜索接口 `client_search_cp` 可用但只能拿到歌曲元数据、**拿不到 MV 播放地址**；新版 `musicu.fcg` 返回 `code:500003`（未登录/需签名）。结论：**QQ 音乐 MV 源技术上无法稳定接入**（即使登录也依赖易失效的动态签名）。片源以 **B 站（主力）+ 网易云（登录后自动扩充）** 为主，已能覆盖绝大多数需求；想听的歌在 B 站/网易云搜同名即可。

## 片源怎么换

视频源默认以 B 站 + 网易云为主，另有方式自由扩充：

1. **顶部「片源」按钮 / 右键菜单「片源管理」** 打开片源面板；

4. 支持：B站链接 / BV 号 / 网易云 MV 链接 / 任意 http(s) 直链 / 本地视频文件。
